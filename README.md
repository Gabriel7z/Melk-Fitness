# Melk

Plano de academia para definir o corpo sem perder o peito: glúteo e coxa maiores, barriga mais chapada, comida e treino no mesmo lugar.

O plano troca gordura por músculo sem subir o peso. Os treinos são quatro dias de força, mais um sábado opcional de postura e caminhada.

Não tem treino de peito. Supino, inclinado e flexão ficaram de fora. O peito se segura com o peso estável e a proteína, não com um dia de peitoral.

Os dados ficam no celular, neste navegador. Não tem conta nem servidor.

## Como rodar

```bash
npm install
npm run dev
```

Abre [http://127.0.0.1:4317](http://127.0.0.1:4317).

## O que tem

- Semana de treino, com a foto da máquina, o passo a passo e a troca se ela estiver ocupada
- Prato de treino e prato de descanso, em comida de mercado
- Peso ideal pela altura, com calorias, proteína e água
- Peso uma vez por semana, na segunda
- Avaliação mensal com a fita, as segundas do mês e a foto de frente e de lado
- Medidas de cintura, quadril, coxa e peito

Isto é um plano geral de recomposição. Não substitui médico, nutricionista nem um profissional de educação física.
